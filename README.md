P&L Lens - offline P&L dashboard
=================================

Files in this folder make up the whole app. Host the folder on any static HTTPS host
(GitHub Pages, Netlify, Cloudflare Pages). Only the app's code is hosted - your P&L
files are read and stored on your own device and never uploaded.

iPhone setup (one time)
1. Open the hosted link in Safari.
2. Share button -> Add to Home Screen.
3. Open P&L Lens from the home screen once while online. After that it works offline.

Each month
1. Save the accountant's .XLS attachment to Files.
2. Open P&L Lens -> Data -> Choose P&L file.
   Every sheet (e.g. "8.26") becomes a month. Existing months are refreshed.

On a computer you can also just double-click index.html.
